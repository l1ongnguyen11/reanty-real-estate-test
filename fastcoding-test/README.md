# Reanty - Real Estate Website

A responsive real estate landing page built with **pure HTML5 and CSS3**, created as a frontend coding test for Fastcoding VN.

## Project Structure

```
fastcoding-test/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles
├── images/
│   └── ...             # Image assets
└── README.md           # This file
```

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, CSS Variables, Media Queries, Pure CSS Checkbox Hack (Mobile Navigation)
- **Zero JavaScript** - 100% Pure HTML5 & CSS3

## Responsive Breakpoints

- **Desktop**: 1024px and above
- **Tablet**: 768px - 1023px
- **Mobile**: below 768px

## How to Run

Simply open `index.html` in a web browser. No build tools or server required.

## Key Design Decisions

- CSS Variables for consistent theming
- BEM-inspired class naming for maintainability
- CSS Grid for multi-column layouts
- Flexbox for component-level alignment
- Pure CSS Checkbox Hack for responsive mobile navigation drawer (No JavaScript required)
- SVG icons for scalability
- System font stack (Arial, Helvetica, sans-serif) for typography

## Browser Support

Tested on modern browsers (Chrome, Firefox, Edge, Safari).
